# Wordle — Hug and Grow Learning Studio

GitHub Pages-ready educational Wordle activity.

## Password
`HugGrowWordle2026!`

## Files
Upload all files in this folder to the root of the same GitHub repository:
- index.html
- style.css
- script.js
- logo.png

The activity includes 11 themed sets with 30 games each, a teacher Customize mode, dictionary validation, on-screen keyboard feedback, celebration sound, and fireworks.


## Dictionary upgrade
This version loads the `dwyl/english-words` alphabetic English word list for much broader guess validation, with a built-in fallback list and extra plural handling. Common words such as ALIENS, BANANA, COFFEE, and COOKIE are accepted.

## Remembering access
After the correct password is entered, the site stores a 30-day first-party cookie plus a localStorage fallback on that browser/device, so returning users normally do not need to enter the password again.
